# erosion

First erosion indicator for field `ks-kearny-01`: **bare days**, i.e. days without a main crop on the field
(from harvest to the next sowing). A rotation is evaluated from the first sowing to the last
harvest, every crop once; the fallow after the last crop is not counted. Generated by `crop_scorer/erosion/erosion.py`
(`uv run python -m crop_scorer.erosion.erosion`, from the repo root).

Uses the same season timeline as `water_usage` (`build_timeline`): sowing and harvest in the middle of the NASS
"most active" windows. If the field is still occupied, sowing moves to 3 days after the previous harvest
while that is inside the full NASS planting window, otherwise to the next year; harvest moves with it. The timeline
does not depend on weather, so every cycle of a rotation looks the same.

| File | Content |
|---|---|
| `bare_days_ranking.csv` | every ordered rotation of 3 crops (125, order and first crop matter), fewest bare days first |
| `rotation_timeline.csv` | the test rotation winter_wheat-corn-sorghum as segments (crop or `fallow`) for a timeline chart |

`bare_days_ranking.csv`: `rotation`, `span_days` (first sowing to last harvest), `bare_days` (smaller is better).
Not yet normalised per year.

`rotation_timeline.csv`: `status` (crop key or `fallow`), `start_date`, `end_date` (both inclusive), `days`, `rotation`.

Not included yet: cover crops, crop residue after harvest, weighting by season (wind), monoculture penalty.
