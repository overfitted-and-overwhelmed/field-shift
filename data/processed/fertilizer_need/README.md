# fertilizer_need

**N fertilizer need** (kg N/ha) for field `ks-kearny-01` (Kearny County, Kansas), test rotation
**winter_wheat → corn → sorghum**, weather 1991–2025. Smaller is better.
Generated by `crop_scorer/fertilizer_need/run.py` (`uv run python -m crop_scorer.fertilizer_need.run`).
Plan: `crop_scorer/fertilizer-need-plan.md`. Sources: `data/fertilizer_sources.md`, `data/base-data/fertilizer_need_sources.md`.

## Method in short

Per crop season (the first season of a run is skipped, its previous crop is unknown):

```
fertilizer = max(0, (removal - own fixation) / fe - mineralization - N from the fallow - credit of the previous crop + cover crop effect)
```

| term | source |
|---|---|
| `removal` = reference yield (t/ha) × N in grain (kg N/t) | NASS Quick Stats yields, N content IFA 2020 via Dryad |
| own fixation (soybean only) = 45 kg N/t grain × yield | IFA 2020 via Dryad |
| `fe` = 0.55 (broadcast, fall-applied) | K-State MF2586 p. 5 |
| mineralization = 20 lb N/ac per 1 % OM (warm season; 10 for wheat) × 1.5 % OM | K-State MF2586; OM from SSURGO 0–23 cm |
| N from the fallow, leaching | see below |
| previous crop credit (soybean): net fixation capped at 0 | plan decision |
| cover crop effect | SARE (Clark 2007), ranges |

Fallow: mineralization adds N to a nitrate pool every day. On days with drainage (`drainage` column of `water_usage`) a share
`1 − exp(−drainage / V)` of the pool is leached, with `V = (1 − θe) × saturated water content` (SWAT+ eq. 4:2.1.2 and 4:2.1.8).
What remains is carried to the next crop, what is lost is reported as `n_leaching_fallow` and charged to the next crop as `n_leaching_charged`.

Cover crop (variants `cover_*`): sown into every fallow where it fits (latest sowing date from `cover_crops.csv`, at least 28 days,
terminated 35 days before planting, winterkilled species at the mean first frost). Rye holds up to 37.5 lb N/ac of the pool against leaching and
adds 27.5 lb N/ac to the next crop's need; vetch credits 75 lb N/ac. Radish has no net number in SARE and is therefore set to 0
(its variant equals `no_cover`).

## Files

`fertilizer_need_season_long.csv`: one row = one value, mean over the start years, per variant, crop and harvest year.
Columns `lat, lon, variant, crop, harvest_year, parameter, value, unit` (kg N/ha, pivot like `water_usage`).

`fertilizer_need_rotation.csv`: per variant the fertilizer need per year of the rotation, mean and 90th percentile over the
start years, leaching, K-State formula as a cross-check (`ksu_formula_mean`), and `balance_unfloored_mean` (before the floor at 0).

Variants: `no_cover`, `cover_cereal_rye`, `cover_hairy_vetch`, `cover_forage_radish`, and sensitivities of `no_cover`
(`theta_low/high` = θe 0.2/0.8, `min_low/high` = mineralization 14/28 lb N/ac per % OM).

## Known gaps / assumptions

- **Reference yields are fixed means, not weather-dependent.** Corn, wheat: NASS district Southwest, non-irrigated (9–10 years, 2010–2019).
  **Sorghum, soybean, sunflower: Kansas, all practices (16 years)**, because no non-irrigated district series exists. This overstates the yield
  of the dryland field. This is also why the 90th percentile over start years hardly differs from the mean: the start years only change
  the weather of the fallow, not the yields.
- Leaching is almost zero (mean 0.03 kg N/ha/year): drainage occurs on few days. This is a result of the water model, not a bug.
- **θe = 0.5 is an assumption.** SWAT+ names the parameter but gives no default. Sensitivity: 0.2/0.8 changes leaching 0.02 to 0.08 kg N/ha.
  Particle density 2.65 g/cm³ (for porosity) is a standard value without citation here.
- The K-State credit (per % OM and year) is not a measured mineralization rate. It is applied per day over the season and over the fallow
  (warm season rate), the fallow part is an assumption. Depth: K-State gives 6 in, we use the 0–23 cm layer.
- The result depends strongly on the mineralization level (24 / 36 / 45 kg N/ha/year for high / mid / low) and on the fallow N.
  The K-State formula (`ksu_formula_mean` 62.5) gives about twice the balance (36.2). It uses expected yield 1.05 × mean, a 30 lb profile N default
  and a wheat adjustment, and has no fallow N carry-over.
- Soybean: no K-State formula (NaN). K-State gives a −40 lb N/ac credit after soybean for warm season crops (the model uses 0, plan decision).
- Cover crop N values are literature ranges (SARE, US-wide, 2007), not Kansas trials. Vetch/legume values are a typical legume range, not
  vetch-specific. Cover crop **water use is not modelled** (Simon 2024: 21 mm less soil water at wheat planting, −11 % sorghum yield).
- Cereal rye has no latest sowing date in SARE; the mean first frost (day 299) is used (assumption).
- `config.py` keeps the hand-copied Dryad values with full citation; `run.py` checks that they equal the selected rows of
  `fertilizer_n_coefficients.csv`.

## Open points (not done yet)

- **Yields:** the plan asked for Kansas, non-irrigated, 1991–2025. That file does not exist (needs a free `NASS_API_KEY` in `.env`).
  The model uses the NASS files already in the repo (2010–2019 / 2010–2025), see above. With a key the yields can be replaced.
- **Mineralization sets the level:** high / mid / low gives 24 / 36 / 45 kg N/ha/year, and the K-State formula gives 62.5. Open:
  which of the two is the main model. The difference comes from the formula's profile N default (30 lb), its 1.05 yield factor,
  and from the balance's fallow N carry-over.
- **Assumptions without a source:** θe = 0.5, particle density 2.65 g/cm³, latest sowing date of cereal rye (mean first frost).
- **Not implemented:** water use of the cover crop (`water_usage`), erosion and bare days (`erosion.py`), a soil health indicator,
  the entry in the criteria register of `rotation-scoring-plan.md`.
- **Limits of the cover crop rule:**
  - The sowing windows close early (latest sowing: radish Sep 28, vetch Oct 11, rye assumed Oct 26). Corn is harvested about Oct 2,
    so after corn rye and vetch fit but radish does not. Sorghum is harvested about Oct 18, so after sorghum only rye fits.
    After winter wheat (harvest late June) all three fit.
  - With the order corn → winter wheat there is no fallow (0 days), so no cover crop can be sown.
  - The dates were checked for the test rotation (winter wheat → corn → sorghum) and by hand for two other rotations, not for all rotations.

## How to check the results

From the repo root:

```
uv run python -m crop_scorer.fertilizer_need.run
```

1. The first line must read `[fertilizer] sanity checks passed`. It tests, among others: removal between 10 and 120 kg N/ha,
   need never negative, more excluded porosity (θe) leaches more, a cover crop never increases leaching, `config.py` equals the CSV.
   If a check fails the script stops with a message.
2. **Reference yields** (printed table): do they look like Kansas dryland yields? (wheat ~2.3 t/ha, corn ~3.7 t/ha.)
3. **Per crop table** at the end: `removal` is what the grain takes up, `fertilizer_need` is what is left to apply after soil supply.
   Check one crop by hand: `removal / 0.55 − mineralization − carried_from_fallow` must equal `fertilizer_need` (soybean: subtract own fixation from removal first).
4. **Compare variants** in `fertilizer_need_rotation.csv`: `no_cover_min_high` must be lower than `no_cover`, `no_cover_min_low` higher;
   `cover_hairy_vetch` must be lowest, `cover_cereal_rye` highest.
5. **Cross-check with K-State**: `ksu_formula_mean` is an independent calculation with the university's own formula. The same order of
   magnitude is expected, not the same number.
6. `water_usage` must not change: run `uv run crop_scorer/water_usage/water_usage.py` and `git status`; the file
   `data/processed/water_usage/irrigation_need_daily_long.csv` must not show up as modified.
