# water_usage

Daily **irrigation need** for field `ks-kearny-01` (Kearny County, Kansas), test rotation
**winter_wheat → corn → sorghum**, weather 1991–2025.
Generated by `crop_scorer/water_usage/water_usage.py` (`uv run crop_scorer/water_usage/water_usage.py`).

## Method in short

1. Every day the crop wants `ETc = Kc × ET0` (FAO-56). ET0 from NASA POWER (`climate_data`), Kc curve from
   FAO-56 Tables 11/12 with stage lengths scaled to the Kansas season (NASS crop calendar).
2. It draws this water from a soil water bucket that only rain refills (FAO-56 ch. 8). Bucket size = SSURGO
   available water capacity down to the max root depth of FAO-56 Table 22 (corn 316 mm, winter wheat 335 mm, sorghum 373 mm).
3. Below a stress threshold the crop only gets a share of ETc (`ETa = Ks × ETc`, FAO-56 eq. 84).
4. **Irrigation need = ETc − ETa** per day: the water the crop is missing.

The rotation is started once in every year 1991–2024 and replayed until 2025, so every crop meets every weather
year. Runs only differ in the soil water they start with; the daily values are averaged over all runs that have
the same crop season.

## File

`irrigation_need_daily_long.csv`: one row = one value (long format like `climate_data`), only days with a crop on the field.

| column | meaning |
|---|---|
| `lat`, `lon` | field location |
| `date` | day |
| `crop` | `winter_wheat`, `corn`, `sorghum` |
| `harvest_year` | harvest year of the crop season (winter wheat sown Oct 2011 → 2012) |
| `sow_date` | sowing day; with `crop` and `harvest_year` it identifies the season (see below) |
| `stage` | FAO-56 growth stage: `ini`, `dev`, `mid`, `late` |
| `parameter`, `value`, `unit` | see below |

| parameter | unit | meaning |
|---|---|---|
| `crop_evapotranspiration` | mm/day | water the crop wants (ETc) |
| `precipitation` | mm/day | rain |
| `irrigation_need` | mm/day | water the crop is missing (ETc − ETa) |

Pivot: `df.pivot_table(index=["date", "crop", "harvest_year", "sow_date"], columns="parameter", values="value")`.
Season total: sum `irrigation_need` per `crop`, `harvest_year` and `sow_date`.

Sowing: each crop goes in at the middle of its NASS most-active planting window. If the previous crop is
still on the field then, it goes in 3 days after that harvest (assumption, same as the explorer calendar),
as long as this is inside the full NASS planting window; otherwise at the target date of the next year.
Harvest moves with sowing (fixed season length). The first crop of a run is never shifted, so some seasons
exist twice in the file (e.g. winter wheat sown Oct 2 as first crop, Oct 21 after sorghum).

## Known gaps / assumptions

- Start: the bucket is 30 % full on Jan 1 of each start year (mean Jan 1 fill level of the simulation itself;
  only affects the first crop of a run).
- Fallow: bare soil evaporates `0.25 × ET0` from the whole bucket (assumption, not an FAO value), calibrated so that
  25 % of the fallow rain stays in the soil, inside the 20–35 % measured for fallow in western Kansas (K-State).
  Real bare soil only dries the top 10–15 cm (FAO-56 ch. 7); that mechanism is not modelled.
- Irrigation need is the daily deficit of a field that is never irrigated. A field that is watered keeps more water
  in the soil, so its real irrigation amount differs (in a test about +10 %).
- Root depth at its maximum from sowing, no runoff, no capillary rise, no Kc climate correction, no year-specific sowing dates.
- Soil from SSURGO dominant component (Ulysses), weather from one NASA POWER cell (~50 km).
